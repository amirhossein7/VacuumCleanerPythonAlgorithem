

# Simulador de Algoritmo de Aspiradora
Esta es una aplicación de simulación de aspiradora que simula el patrón de movimiento de una aspiradora sencilla.
Utilicé este [repositorio](https://gitlab.com/kyxey/vacuum) como base de código para este proyecto.

## Instalación
Utilice Python versión 3 o posterior.

Cree un entorno para ejecutar su proyecto en él (opcional)
``` bash
python3 -m venv yourEnviromentName
```

Utilice el administrador de paquetes [pip](https://pip.pypa.io/en/stable/) para instalar las dependencias.

```bash 
pip install -r requirement.txt
```

## Uso
```bash
python3 vacuum_cleaner.py
```
